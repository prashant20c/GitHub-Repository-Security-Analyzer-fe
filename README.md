# Frontend - GIT Code Analyzer

## Overview

This frontend application provides the user interface for GIT Code Analyzer.

Users can:

* Register and login
* Submit GitHub repository URLs
* View scan results
* Review vulnerabilities
* Read AI-generated recommendations
* Download security reports

## Tech Stack

* Vue 3
* Vue Router
* Pinia
* Axios
* Bootstrap 5
* Chart.js

## Main Pages

* Login
* Register
* Dashboard
* New Scan
* Scan Results
* Finding Details
* Reports

## Installation

```bash
npm install
npm run dev
```

## Environment

```env
VITE_API_URL=http://localhost:8080/api
```

## Features

* Authentication
* Repository Submission
* Vulnerability Dashboard
* Security Score Visualization
* AI Recommendation Viewer
* PDF Report Download
